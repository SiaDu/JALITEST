# User-study analysis snapshot

This directory contains the current aggregate analysis snapshot for the CHI study.

- Current formal dataset: **N=10 usable participants (U01--U10)**.
- Incomplete records and synthetic preview questionnaires are excluded from formal analyses.
- Participant-level raw questionnaire data are intentionally **not committed to this public repository**. They remain in the private Google Drive study folder.
- `paper_user_study_update.tex` is a provisional paper-ready replacement block and should be regenerated after additional participants are collected.
- `results_for_paper.md` summarises the current results and reporting constraints.
- Summary CSVs and figures contain aggregate results only.
- `tools/study/analyze_user_study_results.py` contains the analysis pipeline used to generate these outputs.

The current results are provisional because six additional user-study participants are planned. Re-run the analysis before final paper submission.
